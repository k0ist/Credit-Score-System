\# Credit Score System



Пайплайн машинного обучения, предсказывающий категорию кредитного рейтинга клиента (\*\*Good\*\*, \*\*Standard\*\* или \*\*Poor\*\*) на основе финансовых и поведенческих данных. Проект очищает исходный «шумный» датасет по кредитам, подбирает гиперпараметры для двух классификаторов (Random Forest и CatBoost) с помощью Optuna и статистически сравнивает их качество по кросс-валидационным F1-macro метрикам.



\## Описание



На основе датасета с финансовыми записями клиентов (доход, кредитная история, число займов, просрочки платежей и т.д.) пайплайн выполняет следующее:



1\. Очищает и восстанавливает пропущенные значения в данных, используя `Customer\_ID` для восстановления пропусков по записям одного клиента.

2\. Обучает и настраивает две модели — \*\*Random Forest\*\* и \*\*CatBoost\*\* — с помощью подбора гиперпараметров в Optuna.

3\. Оценивает обе модели с помощью 5-фолдовой стратифицированной кросс-валидации (F1-macro).

4\. Проводит независимый t-тест, чтобы проверить, является ли разница в качестве моделей статистически значимой.

5\. Визуализирует сравнение (метрики по фолдам, распределение, доверительные интервалы и t-распределение).



\## Датасет



Пайплайн ожидает файл `train.csv` в рабочей директории со следующими (как минимум) столбцами:



\- `Customer\_ID`, `Age`, `Annual\_Income`, `Monthly\_Inhand\_Salary`

\- `Num\_Bank\_Accounts`, `Num\_Credit\_Card`, `Interest\_Rate`, `Num\_of\_Loan`

\- `Delay\_from\_due\_date`, `Num\_of\_Delayed\_Payment`, `Changed\_Credit\_Limit`

\- `Num\_Credit\_Inquiries`, `Outstanding\_Debt`, `Credit\_Utilization\_Ratio`

\- `Total\_EMI\_per\_month`, `Amount\_invested\_monthly`, `Monthly\_Balance`

\- `Month`, `Credit\_History\_Age`

\- `Credit\_Score` (целевая переменная: `Good`, `Standard` или `Poor`)



> Это соответствует широко используемому датасету \[«Credit Score Classification» на Kaggle](https://www.kaggle.com/datasets/parisrohan/credit-score-classification).



\## Этапы пайплайна



\### 1. Очистка данных (`clean\_dataset`)

\- Оставляет только строки с корректными значениями целевой переменной (`Good`, `Standard`, `Poor`).

\- Удаляет нечисловые символы из числовых по смыслу столбцов и приводит их к числовому типу.

\- Преобразует названия месяцев в числа.

\- Разбирает поле `Credit\_History\_Age` (например, «5 Years and 3 Months») в общее число месяцев.

\- Заполняет пропуски по каждому клиенту (`Customer\_ID`) методом forward/backward fill, поскольку статичные атрибуты клиента должны быть одинаковыми во всех его записях.



\### 2. Подбор гиперпараметров

\- \*\*Random Forest\*\* — настраивается на стратифицированной подвыборке для ускорения процесса, перебираются `n\_estimators`, `max\_depth` и `min\_samples\_split`, с `class\_weight='balanced'` для борьбы с дисбалансом классов. Числовые признаки передаются как есть, категориальные — кодируются через One-Hot Encoding.

\- \*\*CatBoost\*\* — настраивается на GPU, перебираются `iterations`, `learning\_rate`, `depth` и `l2\_leaf\_reg`. Используется встроенная поддержка категориальных признаков и `RandomOverSampler` для балансировки классов.

\- Обе модели используют \[Optuna](https://optuna.org/) (по 10 испытаний каждая) для максимизации F1-macro.



\### 3. Оценка через кросс-валидацию

Обе настроенные модели переобучаются и оцениваются на полном датасете с помощью 5-фолдовой стратифицированной кросс-валидации, с выводом F1-macro по каждому фолду.



\### 4. Проверка статистической значимости

Независимый двухвыборочный t-тест (`scipy.stats.ttest\_ind`) сравнивает значения F1-macro по фолдам для обеих моделей, чтобы определить, значимо ли одна модель превосходит другую (α = 0.05).



\### 5. Визуализация

Дашборд 2×2, обобщающий сравнение:

\- Линейный график F1-macro по фолдам

\- Boxplot + stripplot с распределением метрик

\- Среднее значение F1-macro с 95% доверительным интервалом

\- t-распределение с отмеченным наблюдаемым t-статистиком



\## Результаты



| Модель | F1-Macro (среднее по CV) | Лучшие параметры |

|---|---|---|

| Random Forest | 0.6529 | `n\_estimators=79, max\_depth=19, min\_samples\_split=3` |

| CatBoost | 0.7083 | `iterations=358, learning\_rate=0.0899, depth=8, l2\_leaf\_reg=0.0575` |



CatBoost статистически значимо превосходит Random Forest (p < 0.05).

\## Примечания



\- Целевая переменная имеет три класса (`Good`, `Standard`, `Poor`); везде используется усреднение F1 по методу macro, чтобы каждый класс учитывался с равным весом независимо от его размера.

\- Дисбаланс классов устраняется с помощью `class\_weight='balanced'` (Random Forest) и случайного oversampling'а (CatBoost).

\- Подбор гиперпараметров выполняется на подвыборке данных для ускорения процесса; финальные модели переобучаются на полном датасете с лучшими найденными параметрами.
